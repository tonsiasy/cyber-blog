1. 防账号枚举

无论查无此人还是密码不符，一律统一响应 401 "用户名或密码错误"，避免暴露已注册账号。

2. 自包含 Salt 提取

bcrypt 不需要独立建表存盐，在字符串头部直接解析出 128 位随机 Salt 与 Cost。

3. 恒定时间盲态比对

内部采用 constant-time comparison 逐字节比对，耗时恒定，杜绝网络时间侧信道攻击。

4. 无状态 JWT 签发

使用 jwt/v5 签发带 72 小时有效期的 Bearer Token，后续文章管理完全无状态放行。
